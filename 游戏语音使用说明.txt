真人麦克风 + 音效一起传给队友
1. 电脑需已有VB-CABLE虚拟音频线路。官方：https://vb-audio.com/Cable/ 。按官方说明安装并重启，再点刷新设备。可在安装完成页选择安装，或在语音板点击“安装虚拟麦克风”，按官方窗口提示安装并重启。
2. “真人麦克风”选择你的实体麦克风；“混音送到”选择CABLE Input；点“开启麦克风混音”。游戏麦克风选CABLE Output，游戏耳机输出保持原设置。
3. 开启后麦克风电平会响应说话，音效和真人麦克风同时送入虚拟线路。游戏自由麦直接说话；按键说话时，真人说话仍按游戏T键，音效触发时软件自动按住T。
4. 麦克风音量独立调节；设0可静音。停止音效不会停止真人麦克风。点击“关闭麦克风混音”才停止转发。
5. 隐藏语音窗口仍会转发麦克风，以便在游戏中使用；退出整个软件会停止。下次启动不会自动开启真人麦克风，需手动点开启。
6. “本地试听设备”仅用于未开启混音时试听；开启混音后音效改送虚拟线路。不要在系统设置中将同一个麦克风再次“侦听”到虚拟线路，以免重复回声。
7. 设备断开会停止混音并提示，重新连接后刷新、重选并开启。混音不会修改系统默认设备。

队友听不到？先点语音板上的“语音自检”
开着麦克风混音，边对麦克风说话边点“语音自检”。它会检查虚拟线路、采样率、静音、隐私权限、游戏正在用哪个设备收音，并实际回听一次 CABLE Output，确认声音真的穿过了虚拟线路。结果也会写进数据目录的 voice-mix.log，反馈问题时请把这个文件一起发来。
常见原因，按出现频率排：
1. 游戏里的麦克风/输入设备没选 CABLE Output，或者选的是“默认设备”。插拔耳机后 Windows 可能自动换默认录音设备，游戏跟着换走。请在游戏里明确选 CABLE Output。开启混音后，状态栏会写出该选的设备全名。
2. 电脑装了多条虚拟线路（如 CABLE-A / CABLE-B、VoiceMeeter），“混音送到”和游戏输入不是同一条。必须配对：选 CABLE-A Input，游戏就选 CABLE-A Output。注意：同一条 VB-CABLE 自带的“CABLE In 16ch”和“CABLE Input”是同一条线路。
3. Windows 麦克风隐私权限关了：设置 → 隐私和安全性 → 麦克风，打开“麦克风访问”和“允许桌面应用访问麦克风”。关掉后游戏读不到 CABLE Output，本软件也读不到实体麦克风（发送电平不动、提示纯静音）。
4. CABLE Input 和 CABLE Output 两端采样率不一致（一个 44100Hz、一个 48000Hz），队友会听到断续或没声音。到 声音设置 → 更多声音设置，在“播放”里的 CABLE Input 和“录制”里的 CABLE Output 上点 属性 → 高级，把默认格式都改成 48000Hz。
5. CABLE Output 或 CABLE Input 在 Windows 里被静音或音量调到 0。
6. 设备被独占：另一个程序独占了麦克风或 CABLE。到该设备 属性 → 高级，取消“允许应用程序独占控制该设备”。
7. 游戏以管理员权限运行而本软件不是：Windows 会拦截本软件替你按 T，按键说话模式下音效发不出去（你自己按 T 说话正常）。请右键本软件“以管理员身份运行”，或游戏开自由麦、本软件选“自由说话”。
8. VB-CABLE 没装好：装完必须重启；如果设备被禁用，在声音设置里右键“显示禁用的设备”把 CABLE 启用。
9. 选错了“真人麦克风”：不要选“立体声混音 / Stereo Mix”，那是电脑内录，会把游戏声音转给队友。
本软件按设备 ID 记住所选设备，不依赖中英文设备名；驱动重装或换 USB 口后 ID 会变，需要点刷新设备重新选一次。
