## 下载与安装（新手照这三步）

1. 在本仓库的 **Releases** 页下载 `FieldTrader-0.8.39-ContactExchange-Setup.exe`。
2. 双击安装。默认装到 `%LOCALAPPDATA%\Programs\FieldTrader`，一路「下一步」即可，无需任何额外设置。
3. 从开始菜单或桌面快捷方式启动。首次启动 Windows 会弹出 UAC（管理员权限），点击「是」。界面显示「管理员模式：已启用」就正常了。

> **首次运行可能出现蓝色提示**「Windows 已保护你的电脑 / Windows protected your PC」。这是因为安装包未购买数字签名证书，并非病毒。点击提示里的 **「更多信息」→「仍要运行」** 即可正常安装。若杀毒软件误报，请对本程序目录添加信任/白名单。

**系统要求**：Windows 10 1809 及以上 64 位。游戏画面比例只有 16:9；16:10、21:9 等屏幕会自动去掉黑边识别，1080p 到 4K 都会统一缩放后识别。GPU 推理走 DirectML（支持绝大多数独显/核显），无合适显卡时自动回退 CPU，普通电脑也能用。

## 使用教程

### 一、听声识物（语音识别）
见 `游戏语音使用说明.txt`。按画面/声音分组匹配，跨声音组太接近会提示「不确定」。

### 二、市场 · 自动兑换
1. 在「① 选择要兑换的商品」里按联络人勾选商品（顺序与游戏内目录一致）。
2. 在「② 兑换设置」里打开**兑换模块**开关，填写**最低利润**（利润 = 产品市价 − 合计价格，达不到的商品会自动跳过看下一件）。**可以不填**：不填就只要不亏就兑换。
3. 勾选启用并开始，4 秒内切回游戏目标详情页。
4. 全局急停见界面显示的快捷键（如 **F8**）。价格变化、商品不符或结果未知会结束本轮，不自动重试；再次开始即新一轮。只有核对到成功证据才入账。

### 三、市场 · 出售
在「④ 出售设置」里打开**出售模块**开关（与兑换共用一个任务队列）。可设本周上架次数上限（0 = 用游戏上限，上架位与本周次数按截图读数，不写死）。可选「有出售收益邮件时自动一键领取并一键回收」。

### 四、自动制造
在「⑤ 自动制造」里开启。识别制造完成后自动领取，并按勾选清单提交并生产。

### 五、全自动兑换（囤货）
在「④ 出售设置」里的**囤货物品**三选一：耐力注射剂 / 100D战地医疗包 / DK8军用防弹面罩（也可选“不囤货”）。打开开关后不用管：
- 每轮先兑换勾选的、已到期的冷却物品，再做制造台、领收益、上架等定时任务；**冷却等待的空档里连续兑换囤货物品**。有物品冷却结束、制造台到点、该领钱或该上架时会先去处理，处理完接着囤。
- 利润按记录到的高峰市价扣手续费估算（不算管理费）（高峰时段再用最新市价封顶）。高峰时段先卖，利润仍够就照样囤。囤货物品自动纳入出售，填写的最低到手价当卖出底价。
- 可设「最多囤多少件」和「仓库至少留多少格」（默认 20 格，留给冷却物品和制造）。

### 六、仓库满了怎么办
程序会自动处理：任何一件发现“空间不足”，就取消本轮剩下的兑换，去出售页点一次「整理」并读取全部仓库的格数（数值相同的几个扩容仓库也分别计算），剩余格数按最后两个仓库算。确认满了就暂停兑换，只做市场监测、高峰出售和领钱（制造台只提交不领取）；卖出后或 30 分钟后再检查，有空间就恢复兑换。

### 七、价格到了就卖
在出售设置里给物品填「最低到手价」后，只要最近看到的价格扣完手续费、每件到手不低于它，**任何时段**都会去上架，不用等高峰。没填最低到手价的物品仍只在高峰时段卖。

### 八、队友听不到游戏语音？
打开「游戏语音」，开着麦克风混音，边对麦克风说话边点 **「语音自检」**，按弹窗里的「问题 / 注意」逐条改。最常见的是：游戏里的麦克风没选 **CABLE Output**（或选成了“默认”）、装了多条虚拟线路配错、Windows 麦克风隐私权限关了、游戏以管理员运行导致自动按 T 被拦截。详见 `游戏语音使用说明.txt`。

## v0.8.39 更新内容

**新增**
- 语音工坊内置音效新增 6 条战术语音：先清理闯入者、离开爆炸范围、准备突破敌方阵型掩护我、遭遇袭击都散开、我们上击溃他们、侧方位遇敌找掩体（快捷键 Ctrl+Shift+9、0、F1～F4）。升级后自动出现。
- 自适应分辨率：16:10、21:9 屏幕上的黑边会被自动去掉，只识别中间的 16:9 游戏画面；1080p、4K 等分辨率统一缩放后再识别，1080p 下小字读得更准。

**修复**
- 囤了很多 100D 后，仓库里的“400”堆叠数被读成补齐价格、市场价读不出来，利润够也一直按 ESC。
- 兑换结果没确认（截图没读全）时，只暂停该商品 5 分钟后重试，不再整次运行都不兑换、不囤货。
- 没勾限时物品却一直去迪克那里看：限时货架看完后 30 分钟内不再进入；“全选”“本组全选”也不再勾上限时物品。

## v0.8.35 更新内容

**修复**
- 补齐道具后游戏提示「物品价格发生变化，部分购买失败」（没买到、补齐价变了）时，按新价重新核利润，够就接着补齐、继续囤货。以前会把商品拉黑，囤货一直不启动。对所有兑换物品都一样。
- 囤货物品兑换结果没确认时，不再每轮把联络人货架从头滚到底空找（表现为一直截图、不点击）。
- 仓库格数漏读：数值相同的几个「扩容仓库150/150」只算一个，或没滚到底就停，导致误判没空间。现在全部仓库都读，剩余格数按最后两个仓库算，提示里列出读到的所有仓库。

**改进**
- 管理费不再参与任何计算。
- 兑换的「最低利润」可以不填：不填就只要不亏就兑换。

## v0.8.33 更新内容

**新增 / 改进**
- 物品与声音库：新建或编辑物品时可以选「占格规格」（1格、2格横放/竖放、3格、4格、6格横放/竖放），已有物品也能改，列表里直接显示规格。
- 游戏语音新增「语音自检」：检查虚拟线路、配对、采样率、静音、隐私权限、默认录音设备、游戏实际收音设备、管理员权限，并实际回听一次虚拟线路。开启混音时自动自检，状态栏写出游戏该选的设备；日志写入数据目录的 voice-mix.log。
- 出售改为「价格到了就卖」，不再只等高峰；没在市场采集的物品每 30 分钟去出售页看一次价格。
- 高峰时段不再停止囤货：先卖，利润够照样囤。

**修复**
- 新加的物品一律是「规格未标注」，主界面按规格筛选时看不到它们。
- 队友听不到时只有笼统报错：独占、隐私权限、设备拔出等改成能照着做的中文提示；麦克风纯静音、默认录音设备被切换时会提示。
- 出售页弹药卡片上的数量「100」被当成「100D战地包」，一直打开错误物品，真正的 100D 卖不出去。
- 出售页预填价格偶尔偏低时直接放弃，现在隔几秒重看几次；仓库里没有的物品不再反复触发出售。
- 手续费前的金币图标被读成多余数字时金额读错。
