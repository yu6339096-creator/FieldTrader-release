## 下载与安装

1. 在本仓库的 **Releases** 页下载 `FieldTrader-0.8.23-ContactExchange-Setup.exe`。
2. 双击安装。默认装到 `%LOCALAPPDATA%\Programs\FieldTrader`，无需联网下载额外组件（本地运行组件、YOLO 与 OCR 模型已内置）。
3. 安装完成后从开始菜单或桌面快捷方式启动。启动器默认请求管理员权限，Windows 弹出 UAC 时点击「是」。界面显示「管理员模式：已启用」即正常。

**系统要求**：Windows 10 1809 及以上 64 位。GPU 推理走 DirectML（支持绝大多数独显/核显），无合适显卡时自动回退 CPU。

## 市场模块激活（机器绑定授权）

市场模块需要作者签发的授权码，**一机一码**：

1. 打开市场窗口，界面会显示本机 **机器码**（16 位，形如 `ABCD-1234-EFGH-5678`）。
2. 把机器码发给作者（见上方联系方式），取得授权码。
3. 把授权码粘贴进输入框激活。授权绑定本机，换电脑需要重新申请。

> 授权采用 ECDSA P-256 签名，作者私钥不随软件分发；授权码无法伪造，也无法挪到别的电脑使用。

## 使用教程

### 一、听声识物（语音识别）
见 `游戏语音使用说明.txt`。按画面/声音分组匹配，跨声音组太接近会提示「不确定」。

### 二、市场 · 自动兑换
1. 在「① 选择要兑换的商品」里按联络人勾选商品（顺序与游戏内目录一致）。
2. 在「② 兑换设置」里打开**兑换模块**开关，填写**最低利润**（利润 = 产品市价 − 合计价格，达不到的商品会自动跳过看下一件）。
3. 勾选启用并开始，4 秒内切回游戏目标详情页。
4. 全局急停见界面显示的快捷键（如 **F8**）。价格变化、商品不符或结果未知会结束本轮，不自动重试；再次开始即新一轮。只有核对到成功证据才入账。

### 三、市场 · 出售
在「④ 出售设置」里打开**出售模块**开关（与兑换共用一个任务队列）。可设本周上架次数上限（0 = 用游戏上限，上架位与本周次数按截图读数，不写死）。可选「有出售收益邮件时自动一键领取并一键回收」。

### 四、自动制造
在「⑤ 自动制造」里开启。识别制造完成后自动领取，并按勾选清单提交并生产。

> 更详细的实测说明见 `市场只读采集实测说明.txt`；版本变更见 `更新说明.txt`。
